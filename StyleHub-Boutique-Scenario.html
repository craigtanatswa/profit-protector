0 · How to Clear Your Current Store Data

⚠ Warning: This permanently deletes all products, sales, inventory and customer records from the app on this device. It does not delete your Supabase cloud account — only the local database. If you have cloud sync enabled, records already pushed to Supabase may re-sync after login. To fully reset, also clear the Supabase tables via the SQL editor.

Method A — Android (recommended, no root required)

  1. Close the Profit Protector app completely.
  2. Open Android Settings (gear icon).
  3. Go to Apps (or Application Manager on older Android).
  4. Find and tap Profit Protector.
  5. Tap Storage & cache.
  6. Tap Clear storage (or Clear data) — not just Clear cache.
  7. Confirm the dialog. The app data is now wiped.
  8. Reopen the app — you will be taken to the setup / login screen.
  9. Log in and re-create the business profile.

Method B — Optional Supabase cloud reset

If you want to also clear the server-side data, run this in the Supabase SQL Editor (replace your_business_id with your actual ID):

DELETE FROM sale_items WHERE sale_id IN (SELECT id FROM sales WHERE business_id = 'your_business_id');
DELETE FROM stock_movements WHERE business_id = 'your_business_id';
DELETE FROM credit_sales WHERE sale_id IN (SELECT id FROM sales WHERE business_id = 'your_business_id');
DELETE FROM payment_records WHERE customer_id IN (SELECT id FROM customers WHERE business_id = 'your_business_id');
DELETE FROM customers WHERE business_id = 'your_business_id';
DELETE FROM sales WHERE business_id = 'your_business_id';
DELETE FROM products WHERE business_id = 'your_business_id';
